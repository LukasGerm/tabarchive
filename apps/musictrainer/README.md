# Music Trainer

A standalone public app at [musictrainer.lukasgermerott.de](https://musictrainer.lukasgermerott.de). No password, account, database, or archive API is required. Choose **Guitar** or **Bass** in the header. Guitar uses standard E–A–D–G–B–E tuning; Bass uses standard four-string E–A–D–G tuning (sounding pitches E1, A1, D2, G2). Your instrument choice is remembered in this browser. Switching instruments starts a fresh question and keeps session totals; a focus on a guitar-only string resets to all strings. Existing saved settings default to Guitar.

The fretboard, string numbers, note answers, chord diagrams, and Learn view follow the selected instrument. Interval and harmony exercises teach the same theory on either instrument:

- **Learn:** browse note names with frets **3, 5, 7, and 9** highlighted. Focus on all four together, one fret at a time, or the full **0–12** neck. Choose sharp or flat spelling, then **Hide notes** to recall them: tap a position to reveal/hide its name, or use arrow keys and Enter/Space. **Hide again** clears the revealed notes. This view has no score; returning to the same exercise preserves your current question and session progress.
- **Playground:** build a progression in any of twelve major or natural-minor keys. Tap a diatonic chord to add it, then select a position to replace, reorder, duplicate, or remove it. Each chord can be a triad or seventh and last 1–8 beats; progressions hold up to 16 chords. Changing key transposes the scale degrees and preserves durations and extensions. Natural minor uses its own seven diatonic chords, including minor v; harmonic-minor alterations and borrowed chords are not included. Starter patterns provide a quick starting point. Play once or loop at 40–200 BPM with full chords, arpeggios, or roots only. Selected chords show their notes, interval roles, and positions on the guitar or bass fretboard. **Hear chord** always plays the complete chord; **Hear each note** plays its tones in root order. **Keep as version A** captures a comparison for the current visit: edit version B, compare their sounds, and inspect shared, added, or removed notes at the selected position. **Practice my progression** connects four perspectives on the selected chord: name it from its numeral, find its root, identify its third, then recall it in the sequence you created. The hidden chord stays silent until answered or revealed. These short lessons have their own result and do not affect quiz totals. The draft, playback settings, and up to 20 named progressions are saved in this browser under `musictrainer:playground:v1`; they work for the current visit if storage is unavailable. Playback starts only on request and stops on edits, playback-setting changes, instrument changes, practice transitions, or navigation.
- **Find a note:** tap a matching fret on the requested string. Open strings and the octave at fret 12 both count when available. Arrow keys move keyboard focus around the fretboard; Enter or Space submits.
- **Name a note** (default): identify the red marker from five answers. The marked string and fret are labeled on the upright neck. Note names include sounding-pitch octaves, such as E2 on guitar or E1 on bass for open low E; switch to note-only labels in Practice settings.
- **Chord shapes:** on Guitar, identify one of 69 open and movable fingerings across 18 chord qualities: major, minor, dominant 7, maj7, m7, dim, dim7, m7♭5, aug, sus2, sus4, 6, m6, add9, m(add9), add11, m(add11), and 9. Bass has a separate four-string catalog across 15 qualities (major, minor, 7, maj7, m7, sus2, sus4, dim, dim7, m7♭5, aug, 6, m6, add9, and m(add9)), with open and movable shapes. Play the notes separately to practice arpeggios. Answers explain the chord tones, and equivalent harmonies never compete as answer choices.
- **Chord tones → Find the root:** tap every root in the named shape. Correct taps stay selected; a question completes only when every root is found. Inversions such as C/E teach the difference between the root and the bass. Only sounding chord notes are selectable; arrow keys move between them, and Enter or Space submits.
- **Chord tones → Note roles:** name the highlighted note’s role, such as root, major third, minor seventh (♭7), or major seventh (7). Answers explain the interval in semitones, label every sounding note in the diagram, and show the chord’s formula and notes. Diminished sevenths, sixths, suspended tones, and added tones retain their distinct roles and correct note spellings. An omitted tone is identified in the breakdown.
- **Intervals → Read notes / By ear:** identify the distance between two pitches. Read correctly spelled notes with octave labels, or hide the pitches and identify the sound by ear. Choose ascending, descending, or together playback. **Foundations** covers minor/major thirds and sevenths, perfect fourths/fifths, and octaves; **Unison–octave** covers all thirteen semitone distances from perfect unison through the octave. Answer reviews reveal both pitches, explain the interval in semitones and frets, and show a distance diagram. Playback starts only on Play, can be replayed without affecting scores, and stops on Stop, answer/reveal, question/settings changes, reset, mode changes, and navigation. Audio uses the same local synthesizer as Harmony. If audio is unavailable, switch to Read notes. Session scores, retries, and reveals follow the other trainer modes.
- **Harmony → Chords in a key:** recall answers without a visible scale or multiple-choice clues. **Mix all three** (the default) asks for chord names from Roman numerals, Roman numerals from chord names, and every note in a chord. Use **Recall** to focus on one direction. Type your answer and press Enter or **Check answer**. Chord names accept common forms such as `Am`, `A minor`, `CM7`, and `Bm7b5`; `#` and `b` work for sharps and flats. Chord tones can be entered in any order, separated by spaces or commas, but must use the key’s spelling. Roman numeral case matters: IV is major four, iv is minor four, and vi is minor six. Reviews explain the actual intervals from the root and show the scale and all seven diatonic chords.
- **Harmony → Chord functions:** identify tonic (I), predominant (ii/IV), or dominant (V/vii°) function. Listen to the tonic followed by the target chord. Context-dependent iii/vi functions are excluded from this introductory exercise.
- **Harmony → Complete a progression:** type the missing chord in a named Roman-numeral pattern, including ii–V–I, I–IV–V–I, turnarounds, pop loops, and plagal/deceptive cadences. Playback leaves the missing chord silent until the answer is resolved; the review explains the progression and the actual upper-note movements used in playback. Questions ask for a specific pattern rather than claiming only one chord could work musically.

Harmony keeps the scale hidden until you answer or ask for help. **Give me a hint** offers a way to reason about the answer; **Show scale** adds the numbered scale as a second hint. Hints mark the question as assisted, so it cannot count toward first-try successes or the streak. Missed, hinted, and revealed answers are queued to return after two intervening answers, without the previous hints or input. Only a first-try answer without hints clears that recall check. Reviews respect the selected key, chord type, exercise, and recall direction; switching settings keeps other checks queued until you return. The review queue is session-only and clears on reset, refresh, or leaving the trainer.

Chord-tone exercises start with **Foundations**: major, minor, 7, maj7, and m7 chords, plus four inversions on Guitar. Select **All chord types** under **Practice settings → Chord vocabulary** to include the full collection. Open/movable/all shape filters apply to both exercises. Partial root answers, retries, reveals, changing modes, and resets use the same session-only progress as the other exercises.

Harmony starts in **C major** with **triads**. Choose any of the twelve major keys or switch to **seventh chords** above the question; note spelling follows the key (including E♯ in F♯ major). Sound is synthesized locally using Web Audio and starts only on Play. Where supported, Play requests a music-playback audio session to avoid [iPhone Silent Mode muting the default ambient session](https://bugs.webkit.org/show_bug.cgi?id=252746). Stop, resolving a question, changing settings/questions, resetting, or leaving Harmony closes playback and clears scheduled notes. The quiz also works visually when audio is unavailable. Harmony shares the trainer’s session totals and resets on refresh. The function model follows the common major-key examples in [Music Theory for the 21st-Century Classroom](https://musictheory.pugetsound.edu/mt21c/HarmonicFunctionInClassicalMusic.html).

The app opens directly into practice, with a cream and green theme and locally bundled typography. It starts with frets **0–12** and all twelve notes selected. Visible range buttons select **0–5**, **0–12**, **5–12**, or **12–24**; both the questions and the displayed neck use that range. Chord mode starts with all shapes and has visible open/movable/all filters. Movable includes both barre chords and compact fingerings with no open strings. The settings button selects a single string or all strings, natural or all twelve notes, sharp or flat spelling, and octave labels. Note names use international B/B♭ notation. Diagrams run from low E on the left to high E (Guitar) or G (Bass) on the right. On a phone, answer choices sit below the upright neck. Name a note puts all five answers in one row. Short screens scroll to preserve readable frets and prevent controls from overlapping; Find a note keeps large fret touch targets. Starting or advancing a question brings its prompt into view.

Retries and revealed answers are separate from first-try successes. Answer counts and streaks live only in React memory: leaving the trainer or refreshing starts over. Trainer settings—including instrument, mode, range, string, note labels, and theory choices—are remembered in this browser. Session scores and recall queues still reset on leaving or refreshing. The trainer requires no database, files, or practice API calls; it is accessible to everyone without login. If browser storage is unavailable, settings work for the current visit.

## Develop and deploy

From the repository root, run `pnpm install --frozen-lockfile` and `pnpm dev:trainer`, then open http://127.0.0.1:3002. Build with `pnpm --filter musictrainer build`; the static output is `apps/musictrainer/dist`.

Run unit tests with `pnpm --filter musictrainer test` and browser tests with `pnpm --filter musictrainer test:browser`. Use `PLAYWRIGHT_CHANNEL=chrome` when using an installed Chrome instead of Playwright's bundled Chromium. The browser suite also tests the audio module directly in a real Web Audio context, so it runs against Vite's development server.

Coolify uses repository base directory `/`, Dockerfile `/apps/musictrainer/Dockerfile`, internal port `3000`, and domain `https://musictrainer.lukasgermerott.de`. The image serves static files with unprivileged Nginx. No environment secrets or persistent volumes are needed. Leave HTTP Basic Authentication disabled. `/healthz` returns `200`; archive API paths and dotfiles return `404`.

Settings are stored under `musictrainer:settings` on this origin. Existing settings on the archive domain cannot be read across origins; choose your preferences once on the new site. Session scores remain in memory only.
